Head-Swapping Technology

This technology integrates advances from HeSer: Few-Shot Head Swapping in the Wild and PIRenderer: Controllable Portrait Image Generation via Semantic Neural Rendering.

Key improvements:
• Fine-tuning the PIRenderer driving model to enhance motion accuracy
• Training a Relight model inspired by HeSer to achieve more natural and seamless head fusion between driving and target videos [Code]
2D Digital Human

This technology trains a LoRA model based on Stable Diffusion 1.5 using a small set of images from the same ID to create virtual idols.

Integrated functions:
• ControlNet
• Inpainting
• T2I-Adapter
• Instruct-Pix2Pix

Together, these components enable flexible and high-quality generation and editing of 2D digital humans. [Code]
Mobile Real-Time Anime Stylization Model

Based on DCT-Net: Domain-Calibrated Translation for Portrait Stylization, this model enables real-time anime-style portrait stylization on mobile devices.

Highlights:
• Mobile-friendly, real-time processing
